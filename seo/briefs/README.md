# Briefs

One file per day the loop decided there was something worth publishing, written by
`seo/opportunities.py`.

A brief is the specification and nothing in it is a guess. Every number came out
of `keywords-au.json`, `competitor-gaps.json` or `gsc-snapshot.json`, and the
table headed "what Google already shows this page for" is Search Console rather
than a keyword tool: real searches where the page was offered and was not good
enough.

They are kept rather than deleted. Six months of these is the record of what the
site decided to chase and why, which is the only way to tell later whether the
ranking arithmetic was any good.
